# Обработка Полной Конверсии Тела

## Реализовано

Корпус ПКТ — отдельное установленное состояние персонажа. В модуле известны
шесть качеств: серийное, тактическое, продвинутое, превосходное, элитное и
абсолютное. Им соответствуют числовые уровни `0–5`. По умолчанию активным может
быть только один корпус. Корпус требует установленную Биосистему, а любой
имплант с trait `pkt` — активный корпус. Пока корпус активен, Биосистему нельзя
извлечь или удалить. При извлечении корпуса его установленные `pkt`-компоненты
извлекаются одним пакетным обновлением.

GM может отдельно ослабить ограничения на количество корпусов, Биосистему,
ПКТ-импланты без корпуса, вместимость баз и качество через мировые настройки
модуля. При нескольких корпусах компоненты готовой модели привязываются к
выбранному совместимому корпусу; снятие другого корпуса их не затрагивает.

Пятнадцать описанных в журнале моделей сохранены в
`flags.cyberpunk-remaster.pktModel` страниц. Обзор журнала собирается из
структурированных данных автоматически.

Источник структуры моделей — `data/pkt-models.json`. Каталог совместимых
заменяемых баз с явными `itemId`, `family` и числовым качеством `0–3` хранится
в `data/pkt-components.json`: 18 заменяемых вариантов и 4 специальные базы.
Обычные записи заменяемы по умолчанию; специальные базы помечаются
`special: true` и `replaceable: false`. HTML страницы остаётся
человеко-читаемым представлением.

Каждая модель хранит:

- обязательный корпус и его качество;
- цену без корпуса;
- один или несколько уникальных компонентов;
- обязательные компоненты и количество;
- семейство компонента;
- внутреннюю пометку участия в общем броске Потери Человечности;
- возможность замены базы;
- блокировку компонента комплектации;
- варианты выбора.

Во вкладке «Хром» модели загружаются именно из этих flags. Карточки появляются
только после установки Биосистемы. Карточка модели показывает минимальное
качество корпуса, цену без корпуса, состав и варианты выбора. Источники Stress
Cost не перечисляются: после установки комплектации остаётся только её карточка
с кнопкой демонтажа.

## Установка модели

Кнопка «Установить модель»:

1. Проверяет наличие Биосистемы и корпуса не ниже минимального качества модели.
   Например, серийные «Близнецы» разрешены на тактическом корпусе.
2. Не позволяет смешивать две готовые модели на одном персонаже.
3. Показывает подтверждение с составом и ценой без автоматического списания
   валюты.
4. Получает исходники предметов из `SF2E Cyberpunk Items`.
5. Создаёт нужное количество embedded Item и переводит equipment в системное
   состояние `implanted`.
6. Назначает каждому экземпляру `pktModelKey`, `pktComponentKey`,
   `pktBodyId`, источник и lock.
7. Раскладывает модули по созданным базам соответствующего семейства с
   предварительной проверкой слотов.
8. Ограничивает Текущую человечность новым Макс с учётом неизменного Hard Cost
   каждого установленного импланта.
9. Складывает кубы всех компонентов с обычным Stress Cost в одну inline-формулу
   на странице модели в журнале. Игрок выполняет бросок и вручную уменьшает
   Текущую Человечность.

Объединение не меняет математический баланс: например, четыре отдельных `1d6`
становятся одним броском `4d6`. Компоненты с пометкой `waived` в формулу не
входят. Inline-бросок подписан названием модели, но источники отдельных кубов
не перечисляются.

Foundry не предоставляет транзакцию для создания и последующего связывания
embedded-документов. Поэтому используется компенсирующая транзакция: при
ошибке связи или проверки удаляются все компоненты, созданные текущей
операцией. Уже существующие предметы персонажа откат не затрагивает.

Кнопка «Демонтировать» удаляет только компоненты выбранной модели. Корпус и
Биосистема остаются у персонажа.

## Замена компонентов

Замена базы допустима, только если:

- совпадает семейство;
- качество нового компонента не выше качества корпуса более чем на одну ступень;
- компонент модели помечен `replaceableBase`;
- новая база вмещает все закреплённые модули.

На карточке такой базы во вкладке «Хром» доступен список **«Замена базы ПКТ»**.
Он строится по структурированному каталогу `data/pkt-components.json`.
После подтверждения модуль:

1. получает новую базу из `SF2E Cyberpunk Items`;
2. устанавливает её с обычным, не отменённым Stress Cost;
3. переносит все дочерние модули без изменения занятых слотов;
4. удаляет старую базу с системным разрешением на замену заблокированного
   компонента;
5. сохраняет ключ модели, компонентный ключ и блокировку на новой базе;
6. пересчитывает Человечность.

Цена показывается справочно и не списывается. При ошибке до удаления старой базы
выполняется компенсирующий откат: модули возвращаются к ней, а созданная новая
база удаляется.

Замена одной базы остаётся отдельной установкой одного импланта. Её Stress Cost
не относится к уже завершённому общему броску модели. Hard Cost новой базы
полностью заменяет Hard Cost старой при очередном пересчёте максимума.

Уникальные и заблокированные компоненты нельзя удалять или извлекать обычной
кнопкой. Защита действует и в `preDeleteItem`/`preUpdateItem`, поэтому штатный
инвентарь не обходит правила вкладки. Снять корпус до демонтажа модели также
нельзя. Исключение задаётся явным `locked: false`: так оформлен расходуемый
ложный мозг «Мудреца», который нужно удалить после срабатывания.

## Особые автоматически выдаваемые механики

Имплант может содержать `flags.cyberpunk-remaster.grantItemUuids`. Пока такой
имплант установлен, модуль добавляет перечисленные черты или заклинания
персонажу. При извлечении импланта удаляются только документы, созданные именно
этим имплантом; уже принадлежавшая персонажу копия не затрагивается.

Эта механика используется для трёх кибердек «Мудреца» и протокола лечения
«Киль-Дары». У каждой деки ровно одна авторская фокусная программа 1-го ранга:
«Оверклок „Хронос“», «Экспертный пакет „Акаша“» или «Контрпрогноз „Оракул
машин“». Флаг
`exclusiveFamily: "cyberdeck"` запрещает одновременно устанавливать две деки.
GM может снять это ограничение мировой настройкой, не меняя сами предметы.

## Намеренно не автоматизировано

Пока остаются в журнале:

- иммунитеты ПКТ;
- ремонт вместо обычной медицины;
- питание глюкозным раствором;
- восстановление HP при переносе;
- сюжетные последствия извлечения Биосистемы.

Для этих эффектов в текущих данных нет достаточно однозначных Rule Element.
Автоматическое вмешательство в лечение, HP и смерть персонажа без отдельного
согласованного дизайна было бы слишком широким.
